# PAGE N4 — Documents: change list, rewrite, sync
KIND: checklist
TAGS: research, normal
TRIGGERS: write up; document; markdown; summary document; update the doc; report; 정리; 문서; change list; rewrite a section; sync the document
OBJECTIVE: Keep the user's documents readable and current, and the model's working files out of the reader's way; change a document only through a committed change list.

ENTRY — object: a K @N4 on a document (D#) and the rows it projects.

◆ List the changes first, commit them, then rewrite whole sections. Never
append a correction to a document.

1. **Register** every document once with `research_doc(action="register")`, as
   one of three roles: source, deliverable, or working (card REF-DOC-ROLES).
2. Read the current text of the document and pass it as `text`.
3. **Plan.** Call `research_doc(action="plan", doc=D#, text)`. It returns a
   draft change list with:
   - the affected sections;
   - sections citing replaced or stale rows;
   - rows not yet in the document;
   - merge candidates;
   - unplanned edits since the last sync.
4. **Commit.** Decide one op per item and commit it with
   `research_doc(action="plan", doc, text, items=[…], session)`. The ops are:
   - rewrite;
   - extend (sec, rows), to bring new rows into an existing section; the
     section's basis must cite them after the rewrite;
   - merge (into);
   - add (rows), one item per new section, listing every row that section
     brings in;
   - retire;
   - keep (why);
   - omit (rows, why).

   The device refuses an incomplete list.
5. **Rewrite** each planned section whole, from the current ledger, following
   the reader rules for a deliverable (card REF-READER). State the current
   result; never keep the old wording with a correction after it. Merge
   sections into one passage. Leave every unplanned section byte-identical.
6. **Sync.** Call `research_doc(action="sync", doc, text=<new text>, session)`.
   The device refuses each of the following:
   - unplanned edits;
   - planned sections left unchanged;
   - citations of replaced or stale rows;
   - reader-lint failures.

**EXITS**

- **a**: document synced → push `await reaction to the document` @USER
- **b**: plan refused as incomplete → push `complete the change list for D#` @N4
- **c**: sync refused → push `fix the listed sections of D#` @N4
- **d**: the document is a source the work is about to rely on → push `check D# before relying on it` @N4-SOURCE

# PAGE REF-RELATIONS — What a dep edge licenses
KIND: reference
TAGS: research, reference
TRIGGERS: relation type; which relation; typed dep edge; sup is not proof; iso map; int map; spec special case; result transfers to general; surface similarity; mathematical resemblance; physical interpretation; cite or rest
OBJECTIVE: What an edge in a dep cell does and does not license, and where the finer relation between two rows is written.

Consulted when deciding whether a row rests on another; return to the step
that sent you.

- A dep edge says one thing: the row rests on its target (syntax in REF-DEP).
  Write an edge only for that. A row that compares with, interprets, specialises
  or is supported by another says so in its evidence cell, in words — and names
  the map, the special case or the kind of support there.
- Support is not proof. A claim becomes `true` through what it rests on, under
  explicit assumptions (its configuration), never through what merely agrees
  with it.
- A result on a special case does not transfer to the general row; say which
  one the evidence covers.
- Mathematical resemblance never makes a row rest on a physical or empirical
  identity.
- Never remove an edge to pass a gate. If the row cannot rest on the target
  (a model row, a proposed one), the row's own standing is what changes: mark it
  model, have the user adopt the target, or move the citation into evidence.

# PAGE START-PRECEDENCE — Abnormal before normal
KIND: reference
TAGS: research, reference
TRIGGERS: abnormal precedence; abnormal before normal; X card; several cards match; which card first; lowest number first; ◆; memory item
OBJECTIVE: Which card runs first when an abnormal (X) card and a normal one both match, and what a ◆ memory item asks.

Consulted when more than one card matches, or a card shows a `◆` item; return to
the step that sent you.

**Abnormal before normal.** An X card takes precedence over a normal one; when
several match, run the lowest number first. `◆` marks a memory item: do it at
once, then run the card.

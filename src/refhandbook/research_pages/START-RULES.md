# PAGE START-RULES — The rules are reviewed, not worked around
KIND: reference
TAGS: research, reference
TRIGGERS: rules review; REVIEW; every 7 sessions; rule change; propose a rule; rule record; cap rule; rule proposal in force; work around a rule; refusals gather; UNAFFECTED disposals; carries and drops
OBJECTIVE: When a rules review comes due, how a rule change is proposed, and that a proposal is not in force until approved.

Consulted when `research_begin` lists REVIEW, or a rule seems to be in the way;
return to the step that sent you.

**The rules are reviewed, not worked around.** Every 7 sessions, or sooner when
refusals, UNAFFECTED disposals, carries and drops gather, `research_begin` lists
REVIEW (card RV). A rule change is proposed as a rule record,
`cap(kind="rule")`; it runs as a warning until the user approves it. Never treat
a proposal as in force.

# PAGE START-LEDGERS — Ledgers are managed, not recreated
KIND: reference
TAGS: research, reference
TRIGGERS: copy a ledger; rename a ledger; delete a ledger; recreate a ledger; start a ledger over; try something on a copy; research_ledgers; research_ledger_delete; confirm
OBJECTIVE: How to copy, rename or delete a ledger instead of recreating it, and when deleting is allowed.

Consulted when a ledger should be copied, renamed, replaced or deleted; return to
the step that sent you.

**Ledgers are managed, not recreated.** `research_ledgers` copies (a sandbox to
try something on) and renames; `research_ledger_delete` deletes, only with
`confirm` set to the ledger id and only when the user asked.

# PAGE REF-CLASSIFY — Classifying an origin is a claim
KIND: reference
TAGS: research, reference
TRIGGERS: classify origin; label origin; mislabeled origin; entailed or model; minimal realization; disown work; own work; label as model; label as user
OBJECTIVE: How to decide an item's origin label against the user's words, and the two mislabelings that are errors.

Consulted when deciding which origin label an item gets, or when a label looks
chosen for convenience; return to the step that sent you.

**Classifying an item's origin is itself a claim.** Compare the item with the
user's words before labeling it.

- Something that realizes the user's described operation in the minimal way is
  `entailed(<quote>)`, even if the model wrote it down.
- Mislabeling in either direction is an error:
  - labeling as `model` in order to disown work;
  - labeling as `user` in order to own work.
